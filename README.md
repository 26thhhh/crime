KANSLOR — Multi-Source Monitoring Dashboard

Linux | Python | SQLite | tmux | Terminal UI | Public Data Integration

A terminal-based monitoring dashboard built to consolidate publicly available 
aviation, weather, police, and fire/EMS information into a single Linux workspace.

KANSLOR is a personal home-lab project exploring systems administration, 
automation, data integration, and monitoring workflows through a
lightweight command-line interface.

Overview

The dashboard organizes multiple independent information sources into four terminal 
panels, allowing users to review different datasets without switching between websites 
or applications.
